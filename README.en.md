# osu! Cursor for Windows

[中文](README.md) | English

Note: Some code was generated by AI.

Windows global cursor overlay:

- Draws the cursor using a 160px click-through WPF window that follows the mouse.
- Temporarily hides the native Windows pointer with transparent system cursors.
- Supports rotation while dragging, scale/glow on press, and hover sound when hovering over clickable elements.
- Restores the original system cursor on exit.
- Sound effect support.


## Run

No installation needed—just double-click the EXE to run.

Or run from source:

```powershell
dotnet run --project OsuCursorWin\OsuCursorWin.csproj
```

Requirements: Windows 10/11 and .NET 8 Desktop Runtime. The program requests administrator privileges and shows a UAC prompt on startup. Because `uiAccess` requires a secure location and a signed executable, running the source build directly may not overlay immersive shell windows such as the Start menu. For normal use, run the installer script:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\install-uiaccess.ps1
```

The settings window opens automatically on first launch and can be reopened from the tray menu. Changes take effect immediately and are saved to `%APPDATA%\OsuCursorWin\settings.json`. Minimizing or closing the settings window only hides it to the background instead of exiting the program.

Tap sound uses `音效\cursor-tap.wav` and plays on both press and release. Hover sound uses `音效\default-hover.wav` and plays when entering clickable elements, with the same 20ms debounce as osu. All audio is played through a dedicated audio thread and a NAudio low-latency WaveOut channel pool. The UI thread only enqueues audio and is not blocked by sound generation or playback.

The program requests administrator privileges by default and uses `uiAccess="true"`, so a UAC prompt appears on first launch. Normal `SetWindowPos` can only change ordering inside the desktop window band and cannot overlay immersive shell windows such as the Start menu. `uiAccess` places the overlay window in the higher `ZBID_UIACCESS` window band.

To enable `uiAccess`, the exe must be located in a secure directory such as `C:\Program Files\` and signed with a locally trusted certificate. The repository provides an installer script:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\install-uiaccess.ps1
```

Run that script as administrator. It stops the current instance, creates and trusts a local code-signing certificate, copies the exe to `C:\Program Files\OsuCursorWin\`, and signs it. After that, launch `C:\Program Files\OsuCursorWin\OsuCursorWin.exe`.

The program uses a low-level mouse hook to receive movement and click events, then renders on demand with WPF. It does not continuously force full-frame refresh, avoiding cursor frame rate drops.

The overlay detects Windows taskbar thumbnail preview windows (`TaskListThumbnailWnd`) and temporarily raises the overlay above the preview window so the cursor is not hidden by taskbar previews.

## Build

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build.ps1
```

The build outputs `publish\OsuCursorWin.exe`. It is a `win-x64` framework-dependent single-file build and requires .NET 8 Desktop Runtime.

## If the Cursor Is Not Restored

Normally, exiting from the tray restores the cursor automatically. If the program is force-killed and the system cursor remains transparent, run:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\restore-cursor.ps1
```

## Notes

- Only Windows 10/11 is supported.
- Exclusive fullscreen games may not show the overlay; borderless or windowed mode is recommended.
- Cursor images come from the original `assets/cursor.png` and `assets/cursor-additive.png`.
- Hover sound requires application support and the effect is not very good. It is recommended to enable the "Play when stretching windows" option so the sound plays when the cursor is over a resizable window border.

## Expected Possible Issues

- The cursor may be covered and disappear when a taskbar app thumbnail preview is open.
- Games that draw their own cursor may show two cursors at the same time.
- ~~In unknown cases, cursor rotation may stutter while dragging and return to normal on release.~~
- Fast cursor movement in File Explorer may cause hover preview tearing.
